# 공부 내용 : CNN부터 전이학습, NLP, 그리고 위클리 1-2(FastAPI 배포)까지 핵심 정리

## CNN

*   작은 필터로 이미지를 부분부분 훑어 특징을 뽑는 신경망이다. 완전 연결 신경망과 달리 위치 정보를 보존하고 가중치 폭발을 막는다.
    

## 합성곱 계층 (Convolutional Layer)

*   필터(커널)가 이미지를 훑으며 특징맵을 만든다.
    
*   패딩 : 가장자리를 0으로 채워 크기 유지
    
*   스트라이드 : 필터가 움직이는 칸 수 (크면 출력 작아짐)
    

## 풀링 계층 (Pooling Layer)

*   특징맵 크기를 줄여 핵심만 남긴다. (Max Pooling 주로 사용) 계산량을 줄이고 위치가 좀 달라도 인식하게 함(위치 불변성).
    

## 평탄화 (Flatten)

*   2D 특징맵을 1D로 펴서 완전 연결 계층에 넘긴다.
    

## CNN 전체 흐름

*   이미지 -> 합성곱 -> ReLU -> 풀링 (반복) -> 평탄화 -> FC -> 분류
    
*   앞부분 = 특징 추출기 / 뒷부분 = 분류기
    

## 사전 훈련 모델 (Pre-trained Model)

*   대규모 데이터로 미리 학습된 모델. (ResNet, VGG16 등) 처음부터 학습할 필요 없이 가져다 쓴다.
    
*   ResNet : 잔차 연결(skip)로 깊어도 학습 잘 됨
    
*   VGG16 : 3x3 필터를 깊게 쌓은 단순한 구조
    

## 전이 학습 (Transfer Learning)

*   사전 훈련 모델의 지식을 새 문제에 가져다 쓰는 기법이다.
    
*   특징 추출(Feature Extraction) -> 앞부분(특징 추출기)은 얼리고, 뒤 분류기만 새로 학습
    
*   Fine Tuning(미세 조정) -> 일부 층의 동결을 풀고 새 데이터에 맞춰 재학습
    

핵심 : 적은 데이터로도 좋은 성능 (남의 학습 결과를 빌려옴)

## 제로샷 학습 (Zero-Shot Learning)

*   한 번도 본 적 없는 클래스도 추론하는 방식. 학습 때 못 본 것을, 의미적 연결로 맞춘다.
    

## 과적합 (Overfitting)

*   학습 데이터에만 너무 맞아 새 데이터에서 성능이 떨어지는 것. (시험 문제만 통째로 외운 학생)
    

## 과소적합 (Underfitting)

*   학습이 덜 돼서 학습 데이터조차 못 맞추는 것.
    

## 조기 중단 (Early Stopping)

*   검증 성능이 더 안 좋아지면 학습을 멈춰 과적합 방지.
    

## 하이퍼파라미터 튜닝

*   학습률, 배치 크기, 층 수 등 사람이 정하는 값을 조정해 성능 최적화.
    

## RNN (순환 신경망)

*   순서가 있는 데이터(문장 등)를 앞에서부터 차례로 처리하는 신경망. 이전 정보를 기억하며 다음을 처리한다.
    
*   한계 : 길어지면 앞쪽 정보가 흐려짐 (기울기 소실)
    

## LSTM (Long Short-Term Memory)

*   RNN의 장기 기억 문제를 게이트로 해결한 구조. 중요한 건 오래 기억하고, 필요 없는 건 잊는다.
    

## Text CNN

*   CNN을 텍스트에 적용한 것. 필터로 단어 n개 묶음(n-gram) 패턴을 잡는다.
    

## Transformer

*   순환 없이 어텐션으로 모든 단어 관계를 한 번에 본다. RNN보다 빠르고 멀리 떨어진 관계도 잘 잡음 (현재 LLM의 기반).
    

## GAN (생성적 적대 신경망)

*   생성자와 판별자가 경쟁하며 진짜 같은 데이터를 만들어내는 모델. (위조범 vs 감별사가 서로 겨루며 둘 다 발전)
    

## 위클리 챌린지 1-2 : FastAPI 배포

*   앞서 구축한 RAG 파이프라인(rag 함수)을 FastAPI로 감싸 외부에서 질문을 보내면 답하는 REST API로 배포했다.
    

핵심 코드

    from fastapi import FastAPI
    from pydantic import BaseModel
    
    app = FastAPI()
    
    class Question(BaseModel):
        question: str
    
    @app.post("/ask")
    def ask(req: Question):
        answer = rag(req.question)
        return {"question": req.question, "answer": answer}

코랩에서 외부 공개 (ngrok) 까지 하였으며, 막혔던 점으로는

테스트 : ngrok 주소 + /docs 로 접속해 Swagger 화면에서 질문 -> 200 응답 + RAG 답변 확인
