### 5) 데이터베이스 기초(고급)

*   팀 프로젝트 : 풀스택, 클라우드
    
*   DB - > RDB -> SQL -> ERD
    
*   Index -> Transaction
    

#### 5-1) ERD

*   ERD 의 고유 명사 : 개체와 관계를 한 눈에 알아볼 수 있도록 그려놓은 도표 -> 설계도
    

#### 5-2) Index

*   Index의 고유 명사 : 데이터베이스 분야에 있어 테이블에 대한 조회 동작의 속도를 높여주는 자료 구조
    
*   full scan 으로 인한 slow query 해결
    

#### 5-3) Full-Text Index

*   Full-Text Index : 텍스트 검색에서 컴퓨터에 저장된 문서 또는 전문 데이터베이스를 검색하는 기법
    
*   텍스트 검색 : 검색 엔진 ElasticSearch
    

#### 5-4) Transcation

*   Transcation 의 고유 명사 : 데이터베이스 관리 시스템 또는 유사한 시스템에서 상호작용의 단위
    
*   사례) 송금, 예약
    

#### 5-5) NoSQL

*   NoSQL : Not only SQL, SQL만을 사용하지 않는 여러 유형의 데이터베이스
    
*   Redis, MongoDB
