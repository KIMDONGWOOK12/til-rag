# NumPy

*   ndarray 는 NumPy의 핵심 자료구조로, 동일한 타입의 데이터를 다차원 배열로 저장함
    

*   ndim 으로 차원 수, shape 으로 형태, dtype 으로 데이터 타입 확인 가능
    
*   astype() 으로 데이터 타입 변환, nbytes 로 메모리 사용량 확인 가능
    
*   정수 인덱싱, 슬라이싱, 불리언 인덱싱, 팬시 인덱싱 4가지 방법으로 데이터 접근 가능
    
*   np.add(), np.subtract(), np.logical\_and() 등 유니버설 함수로 반복문 없이 배열 전체에 연산 적용 가능
    
*   np.mean(), np.std(), np.max(), np.min() 등 통계 연산 지원
    
*   np.dot() 행렬 곱, np.linalg.inv() 역행렬, np.transpose() 전치 등 선형대수 연산 지원
    
*   newaxis 로 차원 추가, reshape() 로 배열 형태 변경 가능
    

## Pandas - 기초

*   Series 는 인덱스를 가지는 1차원 배열 형태의 데이터 구조
    
*   DataFrame 은 행과 열로 구성된 2차원 테이블 형태의 데이터 구조
    
*   head(), tail(), shape, info(), describe() 로 데이터 기본 정보 확인
    
*   iloc 은 정수 기반 인덱싱, loc 은 레이블 기반 인덱싱으로 데이터 접근
    
*   열 추가, 삭제(drop()), 값 수정 등 DataFrame 조작 가능
    

## Pandas - 고급

*   불리언 인덱싱으로 조건에 맞는 데이터 필터링 가능
    
*   &(AND), |(OR), ~(NOT) 논리 연산자로 다중 조건 필터링 가능
    
*   query() 로 SQL과 유사한 방식으로 조건 필터링 가능
    
*   isin() 으로 특정 목록에 속하는 값만 필터링 가능
    
*   str.contains(), str.startswith() 로 문자열 패턴 필터링 가능
    
*   groupby() 로 특정 열 기준 그룹화 후 집계 연산 수행 가능
    
*   agg() 로 여러 집계 함수를 한번에 적용 가능
    
*   transform() 으로 그룹별 계산 결과를 원래 행에 매핑 가능
    
*   merge() 로 공통 열 기준 inner/outer/left/right join 가능
    
*   concat() 으로 데이터프레임 단순 연결 가능
    
*   isnull(), dropna(), fillna(), ffill(), bfill() 로 결측치 탐지 및 처리
    
*   drop\_duplicates(), duplicated() 로 중복 데이터 제거 및 확인
    
*   str.lower(), str.upper(), str.strip(), str.replace() 등 문자열 처리 가능
    
*   pivot(), pivot\_table() 로 데이터 재구성 및 요약 통계 적용 가능
    

## Matplotlib / Seaborn 시각화

*   plt.bar(), plt.barh() 로 막대그래프, 누적형/그룹형 막대그래프 생성
    
*   plt.hist() 로 히스토그램, plt.boxplot() 으로 박스플롯 생성
    
*   subplots() 로 여러 그래프를 한 화면에 배치 가능
    
*   sns.scatterplot(), sns.barplot(), sns.boxplot(), sns.violinplot() 등 Seaborn 시각화
    
*   sns.lineplot() 으로 시계열 데이터 시각화, rolling() 으로 이동평균 계산
    
*   resample() 로 시계열 데이터 리샘플링, interpolate() 로 결측치 보간
    

## SciPy

*   stats.norm.pdf(), stats.norm.cdf(), stats.norm.ppf() 로 정규분포 분석
    
*   stats.describe() 로 기술통계 한번에 확인
    
*   stats.skew(), stats.kurtosis() 로 왜도와 첨도 확인
    
*   IQR 기반 이상치 탐지 : Q3 - Q1 의 1.5배 범위 벗어나면 이상치로 판단
    
*   ttest\_1samp() 로 단일 표본 t검정, ttest\_ind() 로 독립 표본 t검정
    
*   chisquare() 로 카이제곱 검정, f\_oneway() 로 일원분산분석(ANOVA) 수행
