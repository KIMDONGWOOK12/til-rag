*   모델 아키텍처
    
    *   인공 신경망에서 각 레이어의 구성, 연결 방식, 활성화 함수, 입력 및 출력 형태 등 전체 모델의 구조
        
    *   특정 문제를 해결하기 위해 신경망의 구조를 최적화하여 정확도와 호율성을 높이고 최적의 모델을 설계하기 위해서
        
    *   데이터 준비 -> 모델 설계 -> 레이어 추가 -> 모텔 컴파일--> 모델 훈련 -> 모델 평가
        

*   사전 훈련 모델
    
    *   이미 훈련이 끝난 모델 또는 모델 구성요소
        
    *   인공지능 모델을 처음부터 구축하지 않아도 시간과 자원을 절약하며 신속하게 활용할 수 있기 때문
        
    *   사전 훈련 모델을 불러오고, 추가 학습을 시킨 후 모델을 검증
        

*   ResNet
    
    *   입력과 출력 차이를 학습하는 구조를 통해 깊은 신경망의 학습 문제를 해결하고 성능을 향상시키는 인공신경망 모델
        
    *   매우 깊은 신경망에서도 기울기 소실 문제를 효과적으로 해결하여 더 높은 정확도와 성능을 제공하는 딥러닝 모델을 구축할 수 있기 때문에
        
    *   이미지 분류나 특징 추출 등의 작업에서 사전 학습된 ResNet 모델을 불러와 입력 이미지를 전달해 예측 결과를 얻음
        

*   VGG16
    
    *   깊고 구조화된 CNN으로, 16개의 레이어(13개의 합성곱 레이어와 3개의 완전 연결 레이어)로 구성되며 주로 이미지 인식과 분류 작업에 사용되는 사전 훈련된 모델
        
    *   깊은 신경망 구조를 통해 복잡한 이미지 특징을 효과적으로 학습하면서도 전이학습을 활용하여 적은 데이터로도 높은 성능을 낼 수 있기 때문에
        
    *   Keras나 PyTorch를 통해 사전 훈련된 모델을 로드하고, 필요에 따라 미세 조정을 통해 자신의 데이터셋에 맞춰 재학습
        

*   전이학습
    
    *   사전 훈련된 모델을 그대로 사용하거나 추가 튜닝하여 새로운 문제에 적용함으로써 학습 시간을 단축하고 성능을 향상시키는 머신러닝 기법
        
    *   사전 훈련된 모델의 지식을 활용하여 새로운 문제에 대해 더 적은 데이터와 시간으로 높은 성능을 얻기 위해서
        
    *   사전 훈련된 모델의 가중치를 가져와 새로운 데이터셋에 맞게 재훈련 (Fine-tuning, Feature Extraction, Zero-Shot Learning)
        

*   Fine-Tuning
    
    *   사전 훈련된 모델을 새로운 데이터셋에 맞춰 미세 조정하여 성능을 최적화하는 과정
        
    *   새로운 데이터셋에 대해 모델의 성능을 최적화하면서 학습 시간을 단축하고 데이터 부족 문제를 극복하기 위해서
        
    *   사전 학습된 모델의 일부 또는 전체 레이어를 새로운 데이터셋에 맞게 재학습하여 기존 지식을 보존하면서 새로운 작업에 적응시킴
        

*   zerO- Shot Learning
    
    *   훈련 데이터에 없는 새로운 클래스나 작업을 사전 지식이나 관련 정보를 활용하여 학습 없이 수행하는 기법
        
    *   학습 데이터에 없는 새로운 클래스나 작업에도 추가 학습 없이 즉시 대응하기 위해서
        
    *   사전 학습된 모델에 언어적 설명(텍스트), 속성 벡터, 임베딩 등을 입력하여 학습되지 않은 클래스를 추론
        

*   모델 비교
    
    *   모델의 학습 과정과 최종 성능을 나타내는 지표(정확도, 손실 등)를 그래프 등 시각적 도구를 사용하여 표현하는 과정
        
    *   모델의 학습 과정과 성능을 직관적으로 이해하고 문제점을 파악하여 개선할 수 있도록 돕기 위해서
        
    *   Matplotlib의 pyplot 모듈을 사용해서 그래프로 출력
        

*   과적합
    
    *   학습 데이터를 과하게 학습해 실제 데이터에 대해서 오차가 증가하게 되는 것
        
    *   (알아야하는 이유) : 모델이 새로운 데이터에서도 좋은 성능을 발휘하도록 일반화 능력을 높이기 위해서
        
    *   (방지 방법) : 드롭아웃, 데이터 증강, 정규화(L1/L2), 교차 검증, Early Stopping, 앙상블 기법 적용
        

*   과소적합
    
    *   모델이 데이터의 복잡성을 충분히 학습하지 못해 훈련 데이터와 새로운 데이터 모두에서 낮은 성능을 보이는 것
        
    *   알아야하는 이유 : 모델이 학습 데이터의 본질적인 패턴을 충분히 학습하도록 설계 , 최적화할 수 있기 때문에
        
    *   방지 방법 : 더 깊은 모델 사용, ReLU 등 비선형 활성화 함수 활용, 더 많은 데이터 확보, 학습률 및 에포크 조정
        

*   Early Stopping
    
    *   기계 학습에서 경사 하강법과 같은 반복 방법으로 학습할 때 과적합을 방지하기 위해 사용되는 정규화의 한 형태
        
    *   모델이 과적합되는 것을 방지하고 학습 시간을 줄이며 최적의 성능을 보이는 지점에서 학습을 조기에 멈추기 위해서
        
    *   훈련 중 검증 손실을 모니터링하다가 일정 에포크 동안 개선되지 않으면 학습을 자동으로 중단하도록 설정
        

*   하이퍼파라미터 튜닝
    
    *   기계 학습 모델의 성능을 최적화하기 위해 모델의 파라미터 값을 조정하는 과정
        
    *   사전 훈련 모델의 세부 설정을 바꿀 수 있는 중요한 방법 중 하나이기 때문에
        
    *   다양한 하이퍼파라미터 조합을 탐색하고 평가해보며 모델의 성능이 좋아지도록 최적화
        

*   NLP 정규화
    
    *   NLP에서 같은 의미를 가진 서로 다른 표현을 하나의 표준 형태로 통일하는 전처리 기법
        
    *   같은 의미인데 표기만 다른 단어들을 하나로 통일하여 어휘 사전 크기를 줄이고 모델이 동일한 의미를 같은 토큰으로 인식하도록 하기 위해서
        
    *   대소문자 통일, 약어 확장, 유니코드 정규화, 숫자 치환, 공백 정규화 등의 규칙을 텍스트에 순차 적용
        

*   NLP
    
    *   사람이 쓰는 언어인 텍스트와 음성을 컴퓨터가 처리할 수 있는 형태로 바꾸고 그 의미를 분석하거나 새로운 문장을 생성하는 인공지능 및 컴퓨터과학 분야
        
    *   사용자의 검색어, 문의글, 리뷰, 질문 같은 자연어 입력을 분석하여 검색, 분류, 요약, 추천, 챗봇 응답 같은 웹 서비스 기능으로 연결하기 위해서
        
    *   텍스트 ㅊ처리 -> 텍스트 표현(벡터화) -> 모델 학습 -> 모델 평가 및 튜닝
        

*   언어모델
    
    *   NLP에서 문장 내 단어의 확률 분포를 학습해 문장의 자연스러움을 수치로 표현하는 모델
        
    *   문장의 흐름을 수학적으로 예측하고 생성하기 위해 사용
        
    *   말뭉치에서 n개씩 이어진 단어 패턴의 빈도를 세고 앞의 n-1개 단어를 기준으로 다음 단어의 조건부 확률을 계산하는 방식
        

*   N-gram
    
    *   문장에서 앞에 등장한 N-1개의 단어를 기준으로 다음 단어의 조건부 확률을 계산하는 전통적 통계 기반 언어 모델
        
    *   앞의 단어 흐름을 바탕으로 다음 단어를 확률적으로 예측하고 문장의 자연스러움을 계산하기 위해 사용
        
    *   말뭉치에서 연속된 N개의 단어 패턴 빈도를 계산하고 이를 바탕으로 조건부 확률을 구해 다음 단어를 예측하는 방식
        

*   One-Hot Encoding
    
    *   범주형 값을 해당 범주 위치만 1이고 나머지는 0인 고정 길이 벡터로 표현하는 인코딩 방식
        
    *   범주형 값을 순서나 크기 의미 없이 모델이 계산할 수 있는 숫자 벡터로 명확하게 표현하기 위해서
        
    *   정수 인코딩된 토큰의 ID를 인덱스로 사용하여 어휘 크기만큼의 벡터에서 해당 인덱스만 1로 켜고 나머지는 0으로 채우는 것
        

*   world Embedding
    
    *   단어를 고정 차원의 실수 벡터로 변환하여 단어 간의 의미적 유사성과 사용 맥락의 유사성을 반영하는 표현 방식
        
    *   단어의 의미적 유사성을 반영하는 저차원 밀집 벡터로 변환해 더 나은 분석을 위해서
        
    *   gensim의 Word2Vec이나 PyTorch의 Embedding 레이어를 통해 텍스트 데이터를 벡터로 변환
        

*   RNN
    
    *   이전 시점의 hidden state를 다음 시점 계산에 다시 사용하며 순차 데이터를 처리하는 순환 구조의 인공 신경망
        
    *   순차적인 데이터에서 이전 시점의 정보를 기억하고 활용해 순차적 패턴과 종속성을 학습하고 처리하기 위해서
        
    *   순차적인 데이터를 입력으로 받아 시간적 패턴을 학습하고 다음 값을 예측
        

*   LSTM
    
    *   장기 의존성을 안정적으로 학습하도록 설계된 순환 신경망 구조로 cell state와 망각-입력-출력 3개의 게이트를 사용해 정보를 선택적으로 유지 -삭제- 출력함
        
    *   RNN의 기울기 소실 문제로 인해 긴 시차의 의존성을 학습하지 못하는 한계를 해결하기 위해서
        
    *   입력 시퀀스를 시간 순서대로 처리하면서 내부 메모리 상태(cell state)를 유지하고 갱신하는 방식
        

*   BPTT in LSTM
    
    *   LSTM의 순전파 결과에서 손실을 계산한 뒤 hidden state와 cell state를 따라 각 게이트로 기울기를 역전파하여 가중치를 갱신하는 학습 과정
        
    *   셀 상태의 덧셈 경로 덕분에 기울기가 단순 RNN보다 더 안정적으로 과거 시점으로 전달되므로 긴 시퀀스에서도 가중치를 더 잘 학습할 수 있기 때문에
        
    *   PyTorch에서 loss.backward()를 호출하면 LSTM의 모든 게이트와 셀 상태를 거슬러 올라가며 자동으로 기울기가 계산됨
