# 오늘 배운 데이터 분석 핵심 내용 5단 분석법 정리(3단분석 : 정의, 이유, 사용 방법)

## Numpy

### Numpy

*   정의 : 대규모 다차원 배열 및 행렬 연산을 위한 고성능 수학 함수와 도구를 제공하는 파이썬 라이브러리
    
*   이유 : 대규모 수치 데이터를 빠르고 메모리 효율적으로 처리하기 위해서
    
*   방법 : pip install numpy로 설치 후 import numpy as np 로 불러와 사용
    

### Dimension(차원)

*   정의 : 배열에서 데이터를 구성하는 축 (axis)의 개수
    
*   이유 : 데이터를 구조화하여 연산 속도 향상, 메모리 효율성, 수학적 일관성, 코드 간결성을 확보하기 위해서
    
*   방법 : .ndim 속성으로 확인하고, reshape() 와 newaxis 등을 사용해 조정
    

### Shape(형태)

*   정의 : 배열의 각 차원(axis)별 요소 개수를 나타내는 튜플
    
*   이유 : 배열 구조를 명확히 하여 연산의 일관성과 정확성을 보장하기 위해서
    
*   방법 : .shape 속성으로 확인하고, reshape(), resize(), flatten(), ravel(), transpose(), np.newaxis 등으로 조작
    

### Data Type(데이터 타입)

*   정의 : 배열의 각 요소가 가질 수 있는 값의 유형을 지정하는 속성
    
*   이유 : 메모리를 절약하고 연산 속도를 높이기 위해서
    
*   방법 : .dtype 속성으로 확인하고, 생성 시 dtype 인수로 지정하거나 astype() 메서드로 변환
    

### Indexing(인덱싱)

*   정의 : 배열의 특정 요소에 접근하거나 값을 참조하기 위한 방법
    
*   이유 : 배열의 특정 요소에 빠르게 접근하여 데이터를 선택적으로 조작하고 처리하기 위해서
    
*   방법 : 정수, 슬라이싱, 불리언, 팬시 인덱싱을 사용하여 특정 요소에 접근하거나 수정
    

### Operation(연산)

*   정의 : 배열의 요소에 대해 수행되는 수학적 또는 논리적 계산
    
*   이유 : 대량의 데이터를 빠르고 정확하게 처리하여 분석 및 계산의 정확성을 높이기 위해서
    
*   방법 : 배열의 각 요소에 대해 수학적 및 논리적 연산을 수행
    

### Universal Function(유니버설 함수)

*   정의 : 배열의 각 요소에 대해 반복 수행되는 벡터화된 연산을 제공하는 함수
    
*   이유 : 반복문 없이 배열의 요소별 연산을 자동화하여 계산 속도를 높이고 메모리 사용을 최적화하기 위해서
    
*   방법 : np.함수명(배열, 옵션) 형식으로 사용하며, out 매개변수로 결과를 기존 배열에 저장 가능
    

## Pandas

### Pandas

*   정의 : 구조화된 데이터의 조작과 분석을 위한 데이터프레임 및 시리즈 객체를 제공하는 파이썬 라이브러리
    
*   이유 : 데이터를 구조화하여 효과적으로 처리하고 분석할 수 있도록 하기 위해서
    
*   방법 : 라이브러리를 불러오고, 시리즈와 데이터프레임을 생성한 후 다양한 조작 및 분석 기능을 적용
    

### Series(시리즈)

*   정의 : 인덱스를 가지는 1차원 배열 형태의 데이터 구조
    
*   이유 : 데이터를 인덱스를 기준으로 구조화하여 원하는 데이터를 빠르게 조회하고, 연산 및 분석을 간결하게 수행하기 위해
    
*   방법 : 리스트, 딕셔너리 등을 사용해 생성하며 인덱스를 활용해 접근, 수정, 연산, 필터링, 결측치 처리를 수행
    

### Data Frame(데이터 프레임)

*   정의 : 행과 열로 구성된 2차원 테이블 형태의 데이터 구조
    
*   이유 : 데이터를 행과 열 구조로 저장하여 조회, 수정, 분석을 쉽게 수행할 수 있도록 하기 위해서
    
*   방법 : 딕셔너리, 리스트, 넘파이 배열 등 다양한 소스에서 생성하고 조작하여 분석 및 처리 수행
    

### Filtering(필터링)

*   정의 : 조건을 적용하여 데이터 프레임이나 시리즈에서 특정 행이나 값을 선택하는 과정
    
*   이유 : 대량의 데이터에서 원하는 정보를 빠르고 정확하게 추출하여 분석의 신뢰성을 높이기 위해서
    
*   방법 : df\[조건\], query(), isin(), str.contains() 등을 사용하여 특정 조건을 만족하는 데이터 추출
    

### Grouping(그룹화)

*   정의 : 데이터를 특정 기준에 따라 그룹화하여 집계, 변환, 필터링 등의 연산을 수행하는 기능
    
*   이유 : 데이터를 특정 기준으로 체계적으로 분류하여 유의미한 패턴과 통계를 도출하기 위해서
    
*   방법 : groupby() 메서드를 사용하여 특정 열을 기준으로 그룹화하고 집계, 변환, 필터링 연산을 수행
    

### Merging(병합)

*   정의 : 여러 데이터프레임을 공통 열 또는 인덱스를 기준으로 결합하는 과정
    
*   이유 : 서로 다른 데이터 소스를 결합하여 일관된 형식으로 통합하고, 종합적인 분석을 하기 위해서
    
*   방법 : inner, outer, left, right 방식으로 공통된 열이나 인덱스를 기준으로 결합하여 통합
    

### Missing Data Handling(결측치 처리)

*   정의 : 데이터프레임이나 시리즈에서 누락된 값을 탐지하고 제거하거나 대체하는 작업
    
*   이유 : 데이터 ㅂㅜㄴ석의 정확성과 신뢰성을 확보하기 위해서
    
*   방법 : isnull(), dropna(), fillna() 등의 함수를 사용하여 데이터를 탐지, 삭제 또는 특정 값으로 대체
    

### Pivot(피벗)

*   정의 : 데이터를 특정 기준에 따라 재구성하여 요약 통계를 계산하고, 행과 열을 재배치하여 보다 쉽게 분석하는 과정
    
*   이유 : 데이터를 특정 기준에 따라 재구성하여 의미 있는 패턴을 발견하기 위해서
    
*   방법 : pivot() 과 pivot\_table() 을 사용하여 데이터를 특정 기준에 따라 재구성하고 요약 통계를 적용
    

### Duplicates Removal(중복 제거)

*   정의 : 데이터 프레임이나 시리즈에서 동일한 값을 갖는 중복된 행을 식별하고 제거하는 작업
    
*   이유 : 데이터의 정확성과 일관성을 유지하여 신뢰할 수 있는 분석 결과를 도출하기 위해서
    
*   방법 : drop\_duplicates() 로 중복 행을 제거하거나, duplicated() 로 중복 여부를 확인
    

### String Operations(문자열 처리)

*   정의 : 시리즈 객체 또는 문자열이 포함된 데이터프레임에서 문자열 조작 및 변환을 수행하는 기능
    
*   이유 : 비정형 문자열 데이터를 구조화하여 정확하고 일관된 분석이 가능하도록 하기 위해서
    
*   방법 : .str 접근자를 사용하여 시리즈 내 문자열 데이터를 변환, 조작 및 분석
