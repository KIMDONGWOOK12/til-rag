콜랩에서 모델을 만들고 학습/생성까지 확인한 뒤, 맥에서 FastAPI로 웹 서빙까지 완성했습니다.

아직 교재를 보고 그대로 해보는 것밖에 안 되지만, AI를 쓰는 것 또한 실력을 키우는 것이라 배워 클로드 형님과 함께 진행하였습니다.

먼저 아키텍처 구조부터 그린 후, 단계로 쪼갠 뒤 AI와 같이 검토하고 피드백을 받으며 한 단계씩 나아가니 처음에는 막막했지만 할 만해졌습니다.

## 과제 요구사항

1.  사용자가 문장을 넣으면 다음 단어를 생성하는 모델
    
2.  auto-regressive로 완전한 문장 생성
    
3.  FastAPI로 감싸 웹에서 사용
    

CNN, LSTM, Transformer 중 Transformer(디코더 전용, 미니 GPT)를 선택했다. 이유는 현재 모든 LLM의 기반이고,

최종 개인 프로젝트에서도 트랜스포머를 이용하여 진행할것 같다는 생각이 들어 연습하기 좋을거 같아서 선택 하였습니다.

## 전체 로드맵

1.  데이터 준비 (문자 토크나이저)
    
2.  입력/정답 만들기 (다음 글자 맞추기)
    
3.  배치 만들기
    
4.  모델 부품 (Head, MultiHead, FFN, Block)
    
5.  전체 모델 조립 (MiniGPT)
    
6.  학습 (AdamW)
    
7.  생성 (auto-regressive)
    
8.  FastAPI 서빙
    

## 1단계: 문자 단위 토크나이저

*   글자를 숫자로 바꾸는 변환표를 만들었습니다. 한글/영어 상관없이 글자 단위로 처리합니다.
    

    chars = sorted(list(set(text)))

## 2~3단계: 입력/정답 + 배치

*   미니 GPT는 "다음 글자 맞히기"를 학습합니다. 정답(y)은 입력(x)을 한 칸 민 것입니다.
    

    입력 [7, 9, 1, 24, 5, 18, 1] -> 다음: 4

## 4단계: 모델 부품

*   Head: Masked Self-Attention (Q/K/V, 마스킹, softmax)
    
*   MultiHeadAttention: 헤드 여러 개로 다양한 관점에서 문맥 파악
    
*   FeedForward: Linear -> ReLU -> Linear
    
*   Block: 어텐션 + FFN + 잔차 연결 + 레이어 정규화
    

    def forward(self, x):
        x = x + self.sa(self.ln1(x))    # 어텐션 + 잔차 (Pre-Norm)
        x = x + self.ffwd(self.ln2(x))  # FFN + 잔차
        return x

여기에 그동안 배운 게 다 들어가 있었습니다. 토큰 임베딩 / 포지셔널 인코딩 / Self-Attention / Q,K,V / 마스킹 / 잔차 연결 / 레이어 정규화

## 5단계: 전체 모델

*   토큰 임베딩 + 포지셔널 인코딩 -> 디코더 블록 N개 -> Linear + Softmax

## 7단계: 생성 (auto-regressive) - 핵심

글자 하나 예측 -> 다시 입력 -> 반복.

    @torch.no_grad()
    def generate(model, start_text, max_new_tokens=50):
        idx = torch.tensor([encode(start_text)]).to(device)
        for _ in range(max_new_tokens):
            idx_cond = idx[:, -block_size:]
            logits, _ = model(idx_cond)
            probs = F.softmax(logits[:, -1, :], dim=-1)
            idx_next = torch.multinomial(probs, num_samples=1)
            idx = torch.cat((idx, idx_next), dim=1)  # 이어붙이기
        return decode(idx[0].tolist())

## 8단계: FastAPI 서빙

콜랩에서 모델을 저장(minigpt.pth + vocab\_info.json)해서 맥으로 옮겼습니다. 맥에서 [model.py](http://model.py)(모델 정의)와 [main.py](http://main.py)(FastAPI)를 작성하고 실행했습니다.

    model.load_state_dict(torch.load('minigpt.pth', map_location=device))
    
    @app.post("/chat")
    def chat(req: ChatRequest):
        result = generate(model, req.text, max_new_tokens=req.max_tokens)
        return {"input": req.text, "output": result}
