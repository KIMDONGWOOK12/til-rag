## Matplotlib(맷플롯립)

*   고유명사 : 파이썬에서 다양한 형태의 차트와 그래프를 생성할 수 있도록 지원하는 기본적인 데이터 시각화 라이브러리
    
*   사용이유 : 파이썬 환경에서 데이터를 효과적으로 시각화하고, 다양한 유형의 그래프를 유연하게 생성 및 커스터마이징할 수 있기 때문
    
*   사용 방법 : 라이브러리를 불러온 뒤 pyplot을 사용하여 그래프를 생성 및 출력
    

## 시각화(Visualization): 복잡한 데이터나 분석 결과를 사람들이 한눈에 쉽게 이해할 수 있도록 차트, 그래픽, 그림 등 시각적인 형태로 변환하는 기술입니다.

    # 1. 라이브러리 불러오기
    import matplotlib.pyplot as plt

    # 2. 데이터 준비하기
    x = [1, 2,3,4,5] # x축 값
    y = [10,20,30,40,50] # y축 값

    # 3. 그래프 요소 추가 및 그래프 그리기
    
    #그래프 제목 및 축 라벨 설정
    plt.title("Basic Line Graph") # 그래프 제목
    plt.xlabel("X-axis") # x축 라벨
    plt.ylabel("Y-axis") # y축 라벨
    
    #그래프 생성
    plt.plot(x,y) # x,y 데이터를 이용한 선 그래프

    # 4. 그래프 출력하기
    # Matplotlib에서는 plt.show()를 호출해야 그래프가 출력됨
    
    plt.show()
