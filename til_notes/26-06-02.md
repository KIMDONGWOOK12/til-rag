## Tensorflow(feat. Keras) vs PyTorch

### Tensorflow

*   Google Brain팀에서 만든 딥러닝 연산 엔진.
    
*   데이터를 텐서(다차원 배열)로 처리하고 GPU 가속, 자동 미분을 담당함.
    

코드

    import tensorflow as tf
    from tensorflow.keras import layers, models
    import numpy as np
    
    #r가상 데이터 셋 생성
    np.random.seed(0) # 재현성을 위해 난수 시드 설정
    tf.random.set_seed(0) # 모델 학습 과정에서 난수 발생도를 일정하게 고정
    train_data = np.random.rand(1000, 10) # 1000개의 샘플, 각 샘픙은 10개의 특성을 가짐
    train_labels = np.random.randint(2, size=(1000, 1)) # 1000개의 이진 레이블
    
    test_data = np.random.rand(100, 10) # 100개의 테스트 샘플
    test_labels = np.random.randint(2, size=(100, 1)) # 100개의 테스트 이진 레이블
    
    #모델 정의
    model = models.Sequential([
        layers.Dense(16, activation='relu', input_shape=(10,)), # 은닉층 : 16개의 뉴런을 갖는 Dense층, Relu 활성화 함수 사용
        layers.Dense(1, activation='sigmoid') # 출력층 : 1개의 뉴런 시그모이드 활성화 함수 사용
    ])
    
    # 모델 컴파일
    model.compile(optimizer='adam', # optimizer :adam
                  loss = 'binary_crossentropy', # 손실 함수 : binary_crossentropy
                  metrics = ['accuracy']) # 평가지표 : 정확도
    
    #모델 훈련
    model.fit(train_data, train_labels, epochs = 10, batch_size=32)
    
    #모델 평가
    test_loss, test_acc = model.evaluate(test_data, test_labels)
    print(f"Test accuracy :{test_acc}")
    
    #예측하기
    test_data_fixed = np.asarray(test_data, dtype=np.float32) #입력데이터 float32로 변환
    predictions = model.predict(test_data_fixed)
    print(f"first test sample:{predictions[0]}")

### Keras

*   Tensorflow가 너무 복잡해서 나온 간편 인터페이스
    
*   지금은 TF에 통합(tf.keras)
    
*   model.fit() 몇 줄로만으로도 딥러닝 가능
    

### PyTorch <win>

*   Meta가 만든 독립 프레임 워크
    
*   코드 쓰는 즉시 실행되고 (Define-by-run), 파이썬처럼 직관적이다
    
*   현재 논문의 70~80% 가 파이토치 사용.
    

코드

    import torch
    import torch.nn as nn
    import torch.optim as optim
    import numpy as np
    from torch.utils.data import DataLoader, TensorDataset
    
    #가상 데이터셋 생성
    np.random.seed(0) # 재현성을 위해 난수 시드 설정
    train_data = np.random.rand(1000, 10).astype(np.float32) # 1000개의 샘플, 각 샘플은 10개의 특성을 가지고있음
    train_labels = np.random.randint(2, size=(1000, 1)).astype(np.float32) # 1000개의 이진 레이블 생성
    
    test_data = np.random.rand(100, 10).astype(np.float32) # 100개의 테스트 샘플
    test_labels = np.random.randint(2, size=(100, 1)).astype(np.float32) # 100rodml xptmxm dlwls xpdlqmf todtjd
    
    # 텐서 데이터셋 및 데이터 로더 생성 (데이터셋 : 분석이나 머신러닝 모델 학습을 위해 구성된 구조화된 데이터의 모음 )
    train_dataset = TensorDataset(torch.tensor(train_data), torch.tensor(train_labels))
    test_dataset = TensorDataset(torch.tensor(test_data), torch.tensor(test_labels)) 
    
    train_loader = DataLoader(train_dataset, batch_size=32, shuffle=True)
    test_loader = DataLoader(test_dataset, batch_size=32, shuffle=False)
    
    #모델 정의
    class SimpleNN(nn.Module):
      def __init__(self):
        super(SimpleNN, self).__init__()
        self.fc1 = nn.Linear(10,16) #은칙츠이 16개의 뉴럭
        self.fc2 = nn.Linear(16,1) #출력층 : 1개의 뉴련 
        #알레스가 말해주신 아웃풋값이 인풋값으로 가져오기 맞나
    
      def forward(self, x):
        x = torch.relu(self.fc1(x)) # ReLU 활성화 함수
        x = torch.sigmoid(self.fc2(x)) # 시그모이드 활성화 함수
        return x
    
    model = SimpleNN()
    
    #손실 함수 및 옵티마이저 정의
    criterion = nn.BCEWithLogitsLoss()
    optimizer = optim.Adam(model.parameters(), lr=0.001) #아담옵티마이저
    
    #모델 훈련
    for epoch in range(10): #10 eopch
      model.train()
      for batch_data, batch_labels in train_loader:
        optimizer.zero_grad()
        outputs = model(batch_data).squeeze()
        loss = criterion(outputs, batch_labels.squeeze())
        loss.backward()
        optimizer.step()
      print(f"Epoch{epoch+1}, Loss:{loss.item()}")
    
    #modelㅠ평가
    model.eval()
    correct = 0
    total = 0
    with torch.no_grad():
      for batch_data, batch_labels in test_loader:
        outputs = model(batch_data).squeeze()
        predicted = (outputs > 0.5).float()
        total += batch_labels.size(0)
        correct += (predicted == batch_labels.squeeze()).sum().item()
    
    test_acc = correct / total
    print(f"Test accuracy:{test_acc}")
    
    #예측
    model.eval()
    with torch.no_grad():
      sample_output = model(torch.tensor(test_data[0])).item()
      print(f"first test:{sample_output}")

### 파이토치 win

## 데이터 전처리

*   정의: 원본 데이터를 분석 및 모델 학습을 위해 정제하고 변환하는 과정
    
*   이유: 모델 성능 향상 및 신뢰할 수 있는 예측을 위해
    
*   방법: 데이터 수집 -> 결측값 처리 -> 이상치 제거 -> 정규화 ->변환 -> 분할
    
*   핵심: 원-핫 인코딩은 범주형 데이터를 모델이 이해할 수 있는 숫자로 변환
    

## 데이터 증강

*   정의: 기존 데이터를 변형하여 새로운 데이터를 생성하는 기법
    
*   이유: 과적합 방지, 일반화 성능 향상, 데이터 부족 문제 해결
    
*   방법: 회전, 뒤집기, 이동, 크기조정, 밝기조절, 노이즈 추가
    
*   핵심: 복사가 아니라 변형으로 새 데이터 생성
    

## 데이터셋 분할

*   정의: 학습/검증/테스트로 데이터를 분할하여 성능 평가
    
*   이유: 과적합 방지, 객관적 성능 평가
    
*   방법: 직접 분할(슬라이싱) 또는 train\_test\_split() 사용
    
*   핵심: 8:2 또는 6:2:2 비율, 테스트셋은 최종 평가용으로만 사용
    

## 머신러닝

*   정의: 경험을 통해 자동으로 개선하는 컴퓨터 알고리즘 연구 분야
    
*   이유: 복잡한 문제를 데이터로 자동 학습하고 예측하기 위해
    
*   방법: 데이터 수집 -> 전처리 -< 모델 학습 -> 평가 -> 배포
    
*   핵심: 데이터의 패턴(결정 경계)을 스스로 찾아냄
    

## Random Forest

*   정의: 의사결정 트리 기반 앙상블 학습 기법
    
*   이유: 과적합 방지, 노이즈에 강함, 일반화 성능 높음
    
*   방법: 여러 트리 독립 학습 → 다수결/평균으로 최종 예측
    
*   핵심: 배깅 기반, 트리가 많을수록 안정적
    

## K-NN

*   정의: 새로운 데이터를 가장 가까운 K개 이웃과 비교하여 분류하는 알고리즘
    
*   이유: 모델 학습 없이 거리 계산만으로 직관적 분류 가능
    
*   방법: 거리 계산 ->K개 이웃 선택 -> 다수결 분류
    
*   핵심: K값이 작으면 과적합, 크면 과소적합 위험
    

## SVM

*   정의: 데이터를 최적으로 분리하는 초평면을 찾는 지도학습 알고리즘
    
*   이유: 마진 최대화로 일반화 성능 향상, 고차원에서도 안정적
    
*   방법: 서포트 벡터 기반 결정 경계 형성, 커널 트릭으로 비선형 처리
    
*   핵심: 서포트 벡터(경계에서 가장 가까운 점)만이 결정 경계 형성
    

## Naive Bayes

*   정의: 모든 특성이 독립이라 가정하고 베이즈 정리로 확률 계산하는 분류 모델
    
*   이유: 계산 빠름, 텍스트 분류에 강함, 적은 데이터에서도 효과적
    
*   방법: 각 클래스 확률 계산 -> 가장 높은 확률의 클래스로 분류
    
*   핵심: 독립 가정이 비현실적이지만 실제로 잘 작동함
    

## 딥러닝

*   정의: 비선형 모델을 자동으로 만들어 복잡한 패턴을 학습하는 기술
    
*   이유: 특징을 자동으로 학습하고 가중치를 조정하기 때문
    
*   방법: 데이터 준비 -> 모델 설계 -> 학습 -> 평가 -> 최적화
    
*   핵심: 순전파(예측) -> 손실 계산 -> 역전파(가중치 조정) 반복
    

## 퍼셉트론

*   정의: ANN의 기본 단위, 입력값×가중치+편향 -> 활성화 함수 -> 출력
    
*   이유: 이진 분류 문제 해결, 신경망의 기초 단위
    
*   방법: 가중합 계산 -> 활성화 함수 적용 -> 오차만큼 가중치 조정
    
*   핵심: 단층은 XOR 불가, 다층(MLP)은 비선형 문제 해결 가능
    

## 비선형 활성화 함수

*   정의: 신경망에서 뉴런의 출력을 결정하는 비선형 함수
    
*   이유: XOR처럼 선형으로 해결 불가능한 문제를 해결하기 위해
    
*   방법: 시그모이드(0~1), tanh(-1~1), ReLU(0 이상만 통과)
    
*   핵심: 현재 딥러닝에서는 ReLU가 기본으로 사용됨
    

## 인공신경망(ANN)

*   정의: 뇌의 뉴런 네트워크를 모방한 패턴 인식 알고리즘
    
*   이유: 인간 개입 없이 지능적 결정을 내릴 수 있기 때문
    
*   방법: 입력층 -> 은닉층(가중치 계산) -> 출력층
    
*   핵심: 순전파-> 손실계산->역전파-> 가중치 업데이트 반복
    

## FCNN (완전 연결 신경망)

*   정의: 모든 뉴런이 이전 층의 모든 뉴런과 연결된 신경망 구조
    
*   이유: 입력 데이터의 모든 피처를 학습하여 복잡한 패턴 인식 가능
    
*   방법: 데이터 준비 -> 모델 설계 -> 손실함수/옵티마이저 설정 -> 훈련 -> 평가
    
*   핵심: 파라미터 수가 많아 과적합 위험, 모든 ANN이 FCNN은 아님
    

## Fully Connected Layer

*   정의: 모든 입력 뉴런이 모든 출력 뉴런과 연결된 레이어
    
*   이유: 입력 데이터의 모든 특징을 종합하여 복잡한 패턴 학습 및 최종 출력 생성
    
*   방법: TensorFlow -> Dense Layer, PyTorch -> Linear Layer
    
*   핵심: 파라미터 수가 기하급수적으로 증가해 과적합 위험 존재
    

## 손실 함수

*   정의: 예측값과 실제값 간의 차이를 정량적으로 측정하는 함수
    
*   이유: 가중치를 어떻게 조정할지 알려주는 기준이기 때문
    
*   방법: 회귀->MSE/MAE, 분류->크로스 엔트로피
    
*   핵심: 손실 함수는 오차 측정만, 실제 조정은 Optimizer가 담당
    

## 역전파(Backpropagation)

*   정의: 출력층 오차를 기반으로 각 뉴런의 가중치 기울기를 계산하는 알고리즘
    
*   이유: 가중치를 얼마나 조정해야 하는지 계산하기 위해
    
*   방법: 체인룰로 출력층->은닉층->입력층 방향으로 기울기 전파
    
*   핵심: 역전파는 기울기 계산만, 실제 가중치 업데이트는 Optimizer
