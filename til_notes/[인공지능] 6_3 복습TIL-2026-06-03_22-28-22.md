**데이터 전처리**

*   데이터를 분석 및 모델 학습을 위해 원본 데이터를 정제하고 **변환**하는 **과정**
    
    *   결측치 처리 : 누락된 데이터를 식별하고 적절한 값으로 대체
        
    *   이상치 제거 : 데이터 내 비정상적인 값들을 식별하고 제거
        
    *   데이터 정규화 : 데이터를 일정한 범위로 변환하여 모델 학습을 돕는 과정
        
    *   데이터 변환 : 데이터를 로그 변환, 원-핫 인코딩 등으로 변환
        
        *   원-핫 인코딩 : 범주형 데이터를 이진 벡터(이진법으로만 이루어진 벡터)로 변환하는 기법
            
            *   원(one) : 각 범주형 데이터가 벡터에서 하나의 요소만 1(Hot)로 표시됨
                
            *   핫(Hot) : 1로 표시된 요소를 의미함
                

*   일반적으로 이미지 데이터를 벡터로 변환
    
    *   머신 러닝 모델에 입력하기 위해 : 대부분 머신 러닝 알고리즘은 벡터 형태의 입력을 필요함.
        
        *   ㅇㅣ미지 데이터를 벡터로 변환하면 모델이 이미지를 이해하고 처리할 수 있음
            
    *   특징 추출을 위해 : 이미지의 주요 특징을 벡터 형태로 표현하면, 모델이 이미지의 중요한 정보를 학습 가능
        

*   결측값 처리 : 데이터 내에 빠진 값이나 누락된 값을 식별하고 이를 적절한 방법으로 대체하거나 제거하는 과정
    
*   이상치 제거 : 데이터 내에서 정상 범위를 벗어나는 값을 찾아내서 제거하하는 과정
    
*   스케일링 : 다양한 수치 데이터가 있을 때 이를 비교, 분석하기 쉽도록 동일한 범위 또는 척도로 변환하는 과정
    
    *   일반적으로 스케일리은 데이터를 표준화(평균 0, 표준편차 1인 분포) 하거나 정규화(특정 범위, 예를 들어 0과 1 사이로 변환)하는 방법

    def translate_image(image, x, y):
        array = np.array(image) # np.array() 입력 데이터를 NumPy 배열로 변환
