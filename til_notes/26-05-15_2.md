# 계속 배우는 사람

**배운 사람이 아니라 배우는 사람이 되어야 한다**

**5단 분석법**

## CLI

Command Line Interface

일반 명사 :

어떤 행위를 지시하는 말을 이어주는 접점 이라는 것으로 유추 가능하다고 한다.

고유 명사 :

Command : 운영체제나 프로그램에 전달하는 실행 지시어

Line. : 명령을 입력하는 한줄 또는 코드 한줄

Interface. : 사용자와 프로그램, 혹은 시스템 간 상호작용 방식을 정의한 것

사용 이유 :

반복 작업을 자동화하고, 대규모 시스템을 빠르고 일관되게 제어해 생산성을 극대화하기 위해서

사용 방법:

사용자가 명령어를 직접 입력해서 원하는 작업을 실행

Alex가 중간에 언급했던 TUI

**5단 분석법**

## TUI

Text-based User Interface

일반 명사 :

Text. : 글자,본문, 혹은 가공하지 않은 글의 내용

based : ~에 근거를 둔, 어떤 것을 바탕으로 삼는

User : 물건이나 서비스를 직접 사용하는 사람

Interface : 서로 다른 두 대상을 이어주는 접점

즉, 글자에 바탕을 두고 사용하는 사람을 이어주는 접점

고유 명사 :

Text : 터미널이나 콘솔 화면에 표시되는 문자, 기호, 특수문자

based : 격자 형태의 터미널 화면 구조와 텍스트 출력 레이아웃을 활용하는 방식

User : 시스템이나 소프트웨어를 조작하는 주체

Interface : 특수문자나 기호를 조합하여 창, 메뉴, 버튼 모양으로 시각화한 환경

즉, 터미널 창 안에서 선과 ㅏㅇ자 등의 텍스트 기호로 구현된 그래픽 같은 화면을 보며 상호작용하는 방식

사용 이유:

CLI의 강력한 경량성과 원격 제어 효율성을 그대로 유지하면서도, GUI처럼 시각적인 메뉴와 구조를 제공해 조작의 직관성과 편의성을 극대화하기 위해서

사용 방법:

사용자가 명령어를 다 외워서 타이핑하는 대신, 화면에 입체적으로 표시된 텍스트 메뉴나 목록을 키보드 방향키, 탭 키, 엔터 키를 이용해 직접 이동하고 선택하여 작업을 실행

**5단 분석법**

## 모듈

일반 명사: 하나의 큰 시스템을 구성하는 독립적인 단위나 부품

고유 명사: 코드가 들어 있는 하나의 파일(.py)러 변수, 함수, 클래스 등을 담고 있는 독립적인 프로그램 단위( 표준 모둘, 사용자 정의 모듈, 외부 모듈로 나눌 수 있다 #밑에 참고하기)

사용 이유:프로그램을 작은 단위로 나누어서 코드의 재사용성과 가독성, 유지보수성을 높이기 위해서

사용 방법: import를 통해서 불러와 내부 함수와 클래스를 사용

#

표준 모둘:

파이썬이 설치될 때 기본으로 제공되는 모듈입니다.

예시로는 math,os,sys,datetime 가 있습니다.

사용자 정의 모듈:

개발자가 직접 작성한 모듈을 사용자 정의 모듈이라고 부릅니다.

    def hello(name):
      return f"안녕 {name}!"

위 코드와 같이 hello라는 기능이 있는 함수 코드를 개발자가 작성하고 외부에서 불러와 사용할 경우 사용자 정의 모듈을 사용한 것이기 때문에 "안녕 {name}!" 가 출력된다.

### 함수와 모듈의 차이점

함수의 책임은 하나의 일을 어떻게 수행할 것인가에 있으며

모듈의 책임은 이 일들이 어디에 속하는가를 정의하는 것입니다.

이러한 관점에서 보면 모듈은 폴더에 가깝고 함수는 그 폴더 안에서 실제 작업을 수행하는 파일의 역할에 가깝다고 합니다.

외부모듈: 기본 제공되지 않지만, pip와 같은 패키치 관리 도구로 설치하여 사용하는 모듈입니다.

예시로는 numpy,pandas,requests, flask,django가 있습니다.

### PyPI란?

python package index의 약자로 전 세계 파이썬 개발자들이 만든 수십만 개의 오픈소스 패키지들이 모여있는 중앙 저장소입니다.

수 많은 파이썬 러이브러리롸 도구들이 업로드되어 있으며 누구나 검색하고 사용할 수 있다.

pip install 패키지명 명령어를 통해서 패키지 명을 입력하면 pip 도구가 PyPI에서 패키지를 찾아 자동으로 설치합니다.

사용 예시:

    pip install requests

requests 패키지는 HTTP 통신(웹 요청,api 호출 등)을 간편하게 할 수 있도록 도와주는 대표 라이브러리입니다.
