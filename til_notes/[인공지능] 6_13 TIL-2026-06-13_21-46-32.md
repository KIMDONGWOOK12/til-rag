수학(선형대수, 미분, 적분, 확률)의 핵심 개념

수학 핵심 정리

**전체 모토**

*   모든 수학의 계산은 미적분과 선형대수로 끝난다
    

**선형대수**

*   행렬은 함수다
    
    *   선형 변환을 행렬로 표현할 수 있음
        
    *   함수 합성 = 행렬 곱
        
*   선형 변환의 조건
    
    *   T(x + y) = T(x) + T(y)
        
    *   T(kx) = kT(x)
        
    *   둘 다 만족하면 "선형"
        
*   DNN의 FCL이 바로 선형 변환
    
    *   f(x1, x2) = w1· x1 + w2·x2 = \[w1 w2\]\[x1; x2\]
        
    *   즉 완전연결층 = 행렬 곱
        
*   내적(dot product)
    
    *   두 벡터를 곱해 하나의 수로 만듦
        
    *   어텐션의 Q·K도 결국 내적
        

**미분**

*   미분 = 함수의 국소적(Local) 선형 근사
    
    *   특정 점 근처에서 함수를 직선/평면으로 근사한 것
        
*   접평면 예시
    
    *   z = f(xy)의 한 점에서 접평면을 구하면 그게 그 지점의 선형근사
        
*   다변수 일 때
    
    *   미분 행렬 = 야코비 행렬
        

**미분-선대 계산 파이프라인 (중요 포인토)**

함수 -> 미분 -> 선형 함수 -> 선대 -> 행렬 -> GPU(Tensor Core)

*   즉 딥러닝 학습이 GPU에서 빠른 이유
    
    *   미분을 선형 근사로 바꾸고
        
    *   선형 근사를 행렬 연산으로 바꿔서
        
    *   GPU가 행렬 곱을 병렬 처리하기 때문
        

**적분**

*   미분 vs 적분
    
    *   미분 -> 함수의 국소적 선형 근사 (기울기)
        
    *   적분 -> 그래프 아래 넓이, 전체적인 누적/총합
        
*   미적분학 기본 정리
    
    *   따로 발전한 미분과 적분이 사실 연결되어 있음
        
    *   정적분을 부정적분(원시함수)으로 계산 가능
        

**확률**

*   확률은 면적이다 = 집합의 크기다
    
*   확률 공간 3요소
    
    *   표본 공간: 시행 결과 모음 (주사위: {1,2,3,4,5,6})
        
    *   사건 공간: 사건들의 모음
        
    *   확률 측도: 사건 -> 확률값
        
*   확률 변수
    
    *   이름과 달리 "함수"
        
    *   확률 공간 -> 숫자 공간으로 변환
        
*   확률 밀도
    
    *   우리가 자주 보는 확률 밀도가
        
    *   라돈-니코딤 도함수라는 것
        
    *   (수학적으로 깊게 들어가면 르베그 적분 기반)
        
*   핵심만: 확률 = 분포 아래의 넓이를 적분한 것
