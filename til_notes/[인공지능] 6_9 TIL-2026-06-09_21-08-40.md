오늘 배운 내용 (교재 기준) : Fine-Tuning, RNN, LSTM, BPTT in LSTM, Transformer 등

Fine-Tuning

*   사전 훈련된 모델을 새로운 데이터셋에 맞춰 미세 조정하여 성능을 최적화하는 과정
    
    *   사용 이유 : 처음부터 학습하지 않아도 되므로 시간과 데이터 부족 문제를 극복할 수 있음
        
    *   종류 :
        
        *   Full Fine-Tuning: 모든 레이어 재학습
            
        *   Partial Fine-Tuning: 상위 레이어만 재학습, 하위 레이어는 동결
            
        *   단계적 파인튜닝: 상위 -> 하위 순서로 순차 해제
            
        *   하이브리드: 여러 방식 결합
            
    *   동결 :
        
        *   레이어의 가중치를 학습 중에 업데이트하지 않도록 고정하는 것
            
        *   하위 레이어는 이미 기본 특징을 잘 학습했으므로 동결
            
        *   상위 레이어는 새 데이터에 맞게 재학습
            

    for layer in base_model.layers:
        layer.trainable = False      # 하위 레이어 동결
    for layer in model.layers[-4:]:
        layer.trainable = True       # 상위 4개만 학습

RNN

*   이전 시점의 hidden state를 다음 시점 계산에 다시 사용하며 순차 데이터를 처리하는 순환 구조의 인공 신경망
    
    *   사용 이유 : 이전 정보를 기억하며 순차적 패턴과 종속성을 학습하기 위해
        
    *   핵심 동작 : 각 시점마다 현재 입력 + 이전 hidden state ->> 새로운 hidden state 계산
        

    #계산 방법
    h_t = f(W_h * h_{t-1} + W_x * x_t)

*   언어 모델로 보면 n-1개의 단어를 보고 n번째 단어를 예측하는 구조
    
*   한계
    
    *   시퀀스가 길어질수록 초반 정보의 기울기가 거의 0이 됨 (기울기 소실)
        
    *   이 한계를 해결하기 위해 LSTM 등장
        

LSTM(Long-short-term Memory)

*   cell state와 3개의 게이트로 장기 의존성을 안정적으로 학습하도록 설계된 순환 신경망
    
*   사용 이유
    
    *   RNN의 기울기 소실 문제 해결
        
    *   cell state라는 별도 장기 메모리 통로 추가
        
*   RNN과 차이점
    
    *   RNN -> hidden state 하나로 정보 전달
        
    *   LSTM --> hidden state + cell state(장기 메모리) 두 가지로 전달
        
*   3개의 게이트
    
    *   Forget Gate: 이전 기억에서 얼마나 잊을지 결정
        
    *   Input Gate: 새로운 정보를 얼마나 저장할지 결정
        
    *   Output Gate: 현재 상태를 얼마나 출력할지 결정
        
*   cell state 업데이트 : 이전 기억에서 불필요한 부분 삭제 + 새로운 정보 추가
    

BPTT in LSTM

*   LSTM의 순전파 결과에서 손실을 계산한 뒤 cell state를 따라 기울기를 역전파하여 가중치를 갱신하는 학습 과정
    
*   사용 이유 :
    
    *   cell state 갱신이 덧셈으로 이루어져 기울기가 안정적으로 과거로 전달됨
        
    *   RNN은 tanh 미분을 반복해서 거치며 기울기 소실이 심함
        

*   사용 방법 : PyTorch에서 loss.backward() 한 줄로 자동 처리
    
    *   loss.backward() # LSTM 내부 모든 게이트의 기울기 자동 계산
        

Transformer

*   자기어텐션(Self-Attention)을 중심으로 시퀀스 전체의 문맥을 동시에 계산하는 신경망 구조
    
*   사용 이유
    
    *   RNN은 순서대로 처리해서 병렬화 불가, 장기 의존성 학습도 불안정
        
    *   Transformer는 모든 토큰을 동시에 참고해서 두 문제를 함께 해결
        

RNN vs Transformer

*   RNN -> 순차 처리, 이전 hidden state만 참고
    
*   Transformer -> 병렬 처리, 문장 내 모든 토큰을 동시에 참고 (Self-Attention)
    

언어 모델 세대 정리

*   1세대 (통계 기반) -> 빈도표로 다음 단어 예측, 없는 조합은 확률 0
    
*   2세대 (RNN/LSTM) -> 순차 처리, 기울기 소실 문제
    
*   3세대 (Transformer) -> 병렬 처리, 셀프 어텐션, 현재 LLM의 기반
