Seaborn 기초 및 활용

Seaborn

*   정의 : MAtplotlib 을 기반으로 만든 파이썬의 고급 데이터 시각화 라이브러리 입니다.
    
*   사용 이유 : 복잡한 통계 정보를 몇 줄의 짧고 직관적인 코드로 세련되게 표현할 수 있으며, Pandas 데이터프레임과 완벽하게 연동됩니다.
    

*   Matplotlib과의 차이: Matplotlib: 개발자가 일일이 그림을 그리는 저수준(Low-level) 도구.
    

*   Seaborn: 데이터의 구조와 의미를 자동으로 파악해 설명해 주는 고수준(High-level) 도구.
    

Categorical Data(범주형 데이터)

*   정의 : 정해진 그룹이나 레이블을 가지는 데이터
    
*   시각화 방법 :
    
    *   sns.barplot() -> 막대 그래프
        
    *   sns.boxplot() -> 박스 플롯
        
    *   sns.violinplot() -> 바이올린 플롯
        
    *   sns.stripplot() -> 스트립 플롯
        

Continous Data(연속형 데이터)

*   정의 : 특정 구간 내에서 무한한 값을 가질 수 있는 데이터
    
*   시각화 방법 :
    
    *   sns.histplot() -> 히스토그램
        
    *   kde=True -> 커널 밀도 추정 곡선
        
    *   sns.lineplot() -> 선 그래프
        

\-- 시계열 데이터 시각화 --

Time Series Data (시계열 데이터)

*   정의 : 시간의 흐름에 따라 일정한 간격 (초, 분, 시간, 일 , 월, 연 등)으로 측정된 연속적인 데이터
    
*   주요 분석 기법:
    
    *   이동 평균, 이상치 탐지
        

Resampling : 리샘플링

*   정의 : 시계열 데이터의 분석을 위해 데이터의 시간 간격을 재조정하여 다운샘플링 하거나 업샘플링 하는 과정
    
    *   종류:
        
        *   ㄷㅏ운샘플링
            
        *   업샘플링
            

Financial Data(금융 데이터)

*   정의 : 주식 가격, 거래량, 환율, 금리 등 금융 시장에서 발생하는 시계열 기반의 데이터
    
*   분석 적용 : 대용량 틱(초 단위) 데이터를 리샘플링하여 일봉/주봉 등으로 요약하고, 그 위에 이동평균선을 얹어 시각화함으로써 매수/매도 타이밍 및 리스크를 관리하는데 사용
