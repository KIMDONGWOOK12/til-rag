**스레드(Thread)⭐️⭐️**

*   GIL(Global Interpreter Lock) : 파이썬 개발자가 만드시 알아야 하는 개념이다 ->CPython(표준 구현)에서 사용
    

**프로세스(Process)⭐️⭐️**

*   하나의 코어에서는 하나의 프로세스가 실행한다
    
*   하나의 코에서 여러개의 프로세스를 실행 할 때는 프로세스간의 전환(Heavy weight context switching)(Alex note참고)
    
    *   하나의 프로세스 안에서 스레드들 간의 전환은(light weight context switching)
        
*   현대에는 멀티코어를 활용하여 진정한 동시 실행이 가능해졌다.
    
*   AWS, GCP, Colab 서버 코어 : 클라우드 환경은 가상 코어 ( 토큰값이 장난 아닐듯 하다.)
