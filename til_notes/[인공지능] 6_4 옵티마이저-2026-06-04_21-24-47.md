옵티마이저 (Optimizer)

*   딥러닝 모델의 손실 함수를 최소화하기 위해 기울기를 기반으로 가중치를 업데이트하는 과정
    
*   딥러닝 모델의 예측 성능을 향상시키기 위해 손실 함수를 최소화하도록 가중치를 조정하기 위해 사용
    
    *   손실함수가 최소 = 모델의 예측 값이 실제 값과 오차가 많이 나지 않는 것
        

*   학습 과정에서 옵티마이저가 동작하는 순서
    

1.  Feed-Forward : 입력 데이터를 네트워크의 각 층을 통해 순차적으로 전달하여 최종 출력값을 계산
    
2.  Loss function으로 Loss 계산 : 모델의 출력ㄱ값과 실제값 간의 손실을 계산함
    
3.  Backprogagation을 통해 gradient 계산 : 손실을 네트워크의 각 층을 거꾸로 전파하여 각 가중치의 기울기를 계산
    
4.  Optimizer로 weight 조정 : 옵티마이저가 계산된 기울기와 학습률을 사용하여 가중치를 업데이트 함
    

옵티마이저 사용 방법(파이토치)

1.  옵티마이저 선택
    
2.  학습률 설정
    
3.  모델 학습 과정에서 손실 함수를 계산한 후 옵티마이저를 사용해 가중치 업데이트
    

    import torch
    import torch.nn as nn
    import torch.optim as optim
    from torch.utils.data import DataLoader, TensorDataset
    import numpy as np

import torch : PyTorch 자체를 불러오는 것. 텐서 연산, GPU 사용 등 PyTorch의 핵심 기능 전부 포함

import torch.nn as nn : 신경망 관련 모듈. nn.Linear , nn.ReLU, nnConv2d 와 같은 레이어들이 포함

import torch.optim as optim : 옵티마이저 모듈 , optim.SGD, optim.Adam 같은게 있음

from [torch.utils.data](http://torch.utils.data) import DataLoader, TensorDataset : 데이터 로딩 도구. TensorDataset으로 묶고 DataLoader로 배치 단위로 꺼내서 쓰는 것

    num_samples = 1000
    num_classes = 10
    input_shape = (28, 28)
    x_train = np.random.random((num_samples, *input_shape)).astype(np.float32)
    y_train = np.random.randint(num_classes, size=num_samples).astype(np.int64)
    x_test = np.random.random((num_samples // 5, *input_shape)).astype(np.float32)
    y_test = np.random.randint(num_classes, size=num_samples // 5).astype(np.int64)

num\_sample = 1000 : 1000개의 샘플 생성

input\_shape = (28, 28) : 각 샘플의 입력 형태를 28x28 크기로 설정

np.random.random : 0과 1사이의 랜덤한 값을 갖는 입력 데이터를 생성

np.random.randint : 0에서 num\_classes 사이의 정수형 레이블을 생성함

    x_train = torch.tensor(x_train).unsqueeze(1)
    y_train = torch.tensor(y_train)
    x_test = torch.tensor(x_test).unsqueeze(1)
    y_test = torch.tensor(y_test)

torch.tensor : 데이터를 PyTorch텐서로 변환

unsqueeze(1) : 입력 데이터에 채널 차원을 추가하여 (N, 1, 28, 28)형식을 만듬

    # 데이터셋 및 데이터 로더 생성
    train_dataset = TensorDataset(x_train, y_train)
    test_dataset = TensorDataset(x_test, y_test)
    
    train_loader = DataLoader(train_dataset, batch_size=32, shuffle=True)
    test_loader = DataLoader(test_dataset, batch_size=32, shuffle=False)

TensorDataset : 입력과 레이블을 하나의 데이터셋으로 묶음

DataLoader : 데이터셋을 배치 단위로 처리하고 순서를 무작위로 섞어준다 (shuffle\_True)

\# 윗 부분과 따로 구분 된 이유 : 밑에 부분은 파이토치로 읽을 수 있는 형태로 포장 -> 넘파이 배열을 텐서로 변환하고 차원을 맞춘것

\# 넘파이는 그냥 숫자 배열이라 파이토치의 모델이 바로 못받음

1) 텐서로 변환 + 차원 맞추기 (torch.tensor + unsqueeze)

2) 쌍으로 묶기 (TensorDataset)

3) 배치로 포장 (DataLoader)

    # 모델 구성
    class SimpleNN(nn.Module):
     def __init__(self, num_classes=10):
      super(SimpleNN, self).__init__()
      self.flatten = nn.Flatten()
      self.fc1 = nn.Linear(28 * 28, 128)
      self.relu = nn.ReLU()
      self.fc2 = nn.Linear(128, num_classes)
      self.softmax = nn.Softmax(dim=1)
    
     def forward(self, x):
      x = self.flatten(x)
      x = self.fc1(x)
      x = self.relu(x)
      x = self.fc2(x)
      x = self.softmax(x)
      return x
    
    model = SimpleNN(num_classes=num_classes)

nn.Module : 모든 신경망 모듈의 기본 클래스

nn.Flatten() : 입력을 일차원으로 평탄화함

nn.Linear : 선형 변환을 수행하는 완전 연결층

nn.ReLU() : ReLU 활성화 함수

nn.Softmax(dim=1) : 소프트맥스 활성화 함수

    # SGD 옵티마이저 선택 및 학습률 설정
    optimizer = optim.SGD(model.parameters(), lr=0.01)

optim.SGD : 확률적 경사 하강법 옵티마이저 사용

model.parameters() : 모델의 파라미터를 옵티마이저에 전달

lr=0.01 : 학습률을 설정함

    # 손실 함수 정의
    criterion = nn.CrossEntropyLoss()

nn.CrossEntropyLoss() : 다중 클래스 분류 문제에 적합한 손실 함수

    # 모델 학습
    num_epochs = 5
    
    for epoch in range(num_epochs):
     model.train()
     running_loss = 0.0
     for inputs, labels in train_loader:
      optimizer.zero_grad()
      outputs = model(inputs)
      loss = criterion(outputs, labels)
      loss.backward()
      optimizer.step()
      running_loss += loss.item()
     print(f'Epoch{epoch+1}, Loss:{running_loss/len(train_loader)}')

model.train() : 모델을 훈련 모드로 설정

optimizer.zero\_grad() : 옵티마이저의 기울기를 초기화

loss.backward() : 손실에 대한 기울기를 계산

optimizer.step() : 옵티마이저가 파라미터를 업데이트

running\_loss : 배치별 손실을 누적하여 에포크별 평균 손실을 계산

\# 궁금해서 알아본 점 running\_loss/len(train\_loader) : 출력 이유로는 학습이 잘 되고 있으면 에포크가 지날수록 이 값이 점점 줄어드는지 확인하기 위해서

    # 모델 평가
    
    model.eval()
    correct = 0
    total = 0
    with torch.no_grad():
     for inputs, labels in test_loader:
      outputs = model(inputs)
      _, predicted = torch.max(outputs, 1)
      total += labels.size(0)
      correct += (predicted ==labels).sum().item()
    
    accuracy = correct / total
    print(f"Test Accuracy : {accuracy * 100:.2f}%')

model.eval() : 모델을 평가 모드로 설정

torch.no\_grad() : 평가 시 기울기를 계산하지 않도록 설정

torch.max(outputs, 1) : 각 입력에 대해 가장 높은 확률의 클래스를 예측함

정확도를 계산하여 출력

\_, predicted = torch.max(outputs, 1) : output은 뭔지 중요하지 않고 인덱스값만 중요해서 \_를 사용해서 무시? 버린다는 표현을 말함

*   Adam 옵티마이저 사용 예시
    

    optimizer = optim.Adam(model.parameters(), lr=0.001)

optim.Adam : Adam 옵티마이저를 사용하여 모델을 훈련

lr=0.001 : Adam 옵티마이저의 기본 학습률

Adam 옵티마이저는 학습 속도가 빠르고 SGD보다 더 나은 성능을 보이는 경우가 많음

*   경사 하강법 계열 (GD : Gradient Descent)
    
    *   가장 기본적인 옵티마이저
        
    *   딥러닝 모델의 학습 과정에서 손실 함수를 최소화하기 위해 사용되는 대표적인 최적화 알고리즘
        

1) 배치 경사 하강법 (Batch Gradient Descent)

*   전체 데이터셋을 사용하여 한번에 가중치를 업데이트
    
    *   학습 데이터가 1000개일 때 1000개를 다 피드포워드 한 뒤 비용 함수 1회 가중치를 업데이트
        
    *   권장 학습률 : 0.1~ 0.01 / 권장 상황 : 볼록 최적화 문제, 계산 성능이 충분한 경우
        

2) 확률적 경사 하강법 (Stochastic Gradient Descent ( SGD))

*   하나의 데이터 샘플을 사용하여 가중치를 업데이트
    
    *   데이터를 랜덤으로 1개씩 뽑아 업데이트하기 때문에 경로가 가장 불안정하게 튀지만 지역 최솟값 탈출에 유리
        
    *   권장 학습률 : 0.01 ~ 0.001 / 권장 상황 : 데이터가 매우 크거나 연산량이 적은 환경
        

3) 미니 배치 경사 하강법(Mini-batch Gradient Descent)

*   데이터셋을 작은 배치로 나누어 각 배치마다 가중치를 업데이트
    
    *   배치 크기를 100으로 하면 100개 x 10묶음 ->> 에포크당 가중치 업데이트 10번
        
    *   권장 학습률 : 0.01 ~ 0.001 / 권장 상황 : 일반적인 신경망 훈련 (CNN, NLP 등)

적응형 옵티마이저(Adaptive Optimizers)

*   학습률을 동적으로 조정하여 학습 효율을 높여주는 옵티마이저
    

Adagrad

*   자주 발생하는 파라미터 업데이트에 대해 학습률을 낮추고, 드물게 발생하는 업데이트에 대해 학습률을 높임
    
*   단점 : G\_t가 계속 누적되기 때문에 학습 후반에 학습률이 거의 0에 수렴
    
*   권장 학습률 : 0.01 / 권장 상황 : 희소 데이터셋, NLP, 추천 시스템
    
    ![file_y0ynw6TSF3Ktjg7VQS](https://exp-upload.goorm.io/2026-06-04/á/y0ynw6TSF3Ktjg7VQSwebp)

RMSprop

*   학습률을 조정하면서 과거의 기울기를 반영하여 업데이트
    
*   지수 이동 평균(EMA)을 적용해 Adagrad의 학습률 소멸 문제를 해결
    
*   γ(감쇠율)로 최근 기울기에 더 큰 가중치를 부여하고 과거 기울기의 영향을 점점 줄임
    
*   권장 학습률 : 0.001 / 권장 상황 : RNN/LSTM, 강화학습

Adam

*   모멘텀과 RMSprop의 장점을 결합하여 학습률을 조정. 현재 가장 널리 사용되는 옵티마이저
    
*   모멘트 : 통계에서 적률을 의미
    
    *   1차 모멘트(m) : 평균 -> 모멘텀 계열 계수. 기울기의 이동 평균으로 방향 정보를 담음
        
    *   2차 모멘트(v) : 분산 -> RMSprop 계열 계수. 기울기 제곱의 이동 평균으로 크기 정보를 담음
        
*   초기 스텝에서 값이 0에 편향되는 문제를 편향 보정(bias correction)으로 해결
    
*   권장 학습률 : 0.001 / 권장 상황 : 대부분의 신경망 (CNN, 트랜스포머 등)
